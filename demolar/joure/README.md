# JOURE Perfume · 3B konsept demo

> Bu sayfa JOURE Perfume için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün görselleri, notalar ve metinler markanın sitesinden (joureperfume.com) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
