# Lalive · 3B konsept demo

> Bu sayfa Lalive için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ambalaj ve etiket görselleri temsilidir; ürün açıklamaları markanın yayımladığı bilgilerden derlenmiştir, fiyatlar örnektir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
