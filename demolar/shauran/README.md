# Shauran Paris · 3B konsept demo

> Bu sayfa Shauran Paris için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün görselleri, notalar ve metinler markanın satış noktalarından (vgcharme.com, scentsangel.com) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
