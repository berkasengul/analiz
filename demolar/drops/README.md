# DROPS · 3B konsept demo

> Bu sayfa Drops Parfumerie için hazırlanmış bağımsız bir konsept demodur ve mağaza sahibiyle bağlantılı değildir. Ürün görselleri, açıklamalar ve fiyatlar mağazanın kendi sitesinden (dropsparfumerie.com) alınmıştır; ürün ve marka adları sahiplerine aittir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
