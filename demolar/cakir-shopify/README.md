# Çakır Parfümeri · 3B konsept demo

> Bu sayfa Çakır Parfümeri için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün fotoğrafı, açıklamaları ve fiyatları markanın mağazasından (cakirparfumeri.com.tr) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
