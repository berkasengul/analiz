# HAREMLIQUE · 3B konsept demo

> Bu sayfa Haremlique Istanbul için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün görselleri, notalar, fiyatlar ve metinler markanın kendi sitesinden (haremlique.com) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
