# MISK+ANBER · 3B konsept demo

> Bu sayfa MISK+ANBER için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün görselleri, açıklamalar ve fiyatlar mağazanın kendi sitesinden (miskanber.com) alınmıştır; ürün ve marka adları sahiplerine aittir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
