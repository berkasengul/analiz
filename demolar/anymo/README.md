# ANYMO Paris · 3B konsept demo

> Bu sayfa ANYMO Paris için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün fotoğrafları, açıklamaları ve fiyatları markanın mağazasından (anymoparfum.com) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
