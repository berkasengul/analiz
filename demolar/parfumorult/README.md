# Parfümőrült · 3B konsept demo

> Ez az oldal a Parfümőrült számára készült független koncepció demó, és nem áll kapcsolatban a márka tulajdonosával. A termékfotók, leírások és árak a parfumorult.hu oldalról származnak.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
