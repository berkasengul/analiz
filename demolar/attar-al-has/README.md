# Attar al Has · 3B konsept demo

> Bu sayfa Attar al Has için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün fotoğrafları, açıklamaları ve fiyatları markanın sitesinden (attaralhas.com) alınmıştır; Türkçe metinler markanın metinlerinin çevirisidir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
