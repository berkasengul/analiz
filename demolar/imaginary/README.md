# IMAGINARY AUTHORS · 3B konsept demo

> Bu sayfa Imaginary Authors için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün görselleri, açıklamalar ve fiyatlar markanın kendi sitesinden (imaginaryauthors.com) alınmıştır; ürün ve marka adları sahiplerine aittir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
