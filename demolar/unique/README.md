# Unique'e Luxury · 3B konsept demo

> Bu sayfa Unique'e Luxury için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün fotoğrafları, açıklamaları ve fiyatları markanın sitesinden (uniqueeluxury.com) alınmıştır; Türkçe metinler markanın İngilizce metinlerinin çevirisidir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
