# Seven Gates · 3B konsept demo

> Bu sayfa Seven Gates için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Şişe ve etiket görselleri temsilidir; Cihan Engin'in orijinal illüstrasyonları yerine geçici çizimler kullanılmıştır. Ürün açıklamaları ve fiyatlar örnektir.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
