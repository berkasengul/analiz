# Régalien · 3B konsept demo

> Bu sayfa Régalien için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün fotoğrafları, açıklamaları ve fiyatları markanın sitesinden (regalien.com) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
