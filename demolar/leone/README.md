# LEONE DI FIUME · 3B konsept demo

> Bu sayfa Leone di Fiume için hazırlanmış bağımsız bir konsept demodur ve marka sahibiyle bağlantılı değildir. Ürün görselleri, koku profilleri, fiyatlar ve metinler markanın kendi sitesinden (leonedifiume.com) alınmıştır.

Demo fabrikasıyla (demo-fabrikasi/) üretildi. İçerik `src/content.json` dosyasında.

```bash
npm install
npm run dev
```
